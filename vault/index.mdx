# Dongzhe 知识库

> LLM Wiki 模式的知识库：Obsidian 是 IDE，LLM 是 programmer，wiki 是 codebase。

本站由 [Blume](https://useblume.dev) 从 Obsidian Vault 自动构建。内容按三层架构组织：

## 三层架构

| 层 | 内容 | 入口 |
|---|---|---|
| **raw/** | 外部素材：论文、文章、访谈原文（immutable） | [raw/ 门户](/raw/) |
| **wiki/** | LLM 编译的结构化知识：概念、主题地图、关联 | [wiki/ 索引](/wiki/_index/) |
| **output/** | 查询产出：深度报告、对比分析、幻灯片 | [output/ 门户](/output/) |

## 快速入口

### wiki/ — 编译知识

- [索引](/wiki/_index/) · [摘要速查](/wiki/_summaries/) · [时间线](/wiki/log/)
- 概念：`/wiki/concepts/`（如 [agent-communication](/wiki/concepts/agent-communication/)）
- 地图：`/wiki/maps/` · 关联：`/wiki/connections/`

### output/ — 查询产出

- [深度报告](/output/reports/) · [创业想法](/output/ideas/_index/)

### raw/ — 原始素材

- [文章](/raw/articles/) · [论文](/raw/papers/) · [项目](/raw/projects/) · [Inbox](/raw/Inbox/)

## 说明

- 本站在 **副本** 上构建，原始 Vault 内容零改动
- 每页右上角可 **Copy as Markdown**；任意页 URL 追加 `.md` 直接获取原始 Markdown（AI 友好）
- 站点自动生成 `llms.txt` 供 LLM 消费
