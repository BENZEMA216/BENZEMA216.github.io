## 核心命题

Agent 生态的核心问题是 **"能力孤岛 + 创作者零激励"**:
- 每个 agent 是孤岛, 不能互相调用
- 创作者做了好用的 agent / skill, 没有变现通道
- Skill 变现的核心矛盾是 "交付即泄密"

需要一个平台让 agent 互相调用, 创作者能变现。

## 核心信念 (多次表达)

1. **"平台变现模式应该像 Shopify: 低抽成维护关系, 不是收税"**
2. **"Agent 是零摩擦信息贡献者, 这才是它不可替代的地方"**
3. **"Skill 变现失败的核心矛盾是'交付即泄密'"**
4. **"MVP 核心是让创作者直接把自己的 agent 给别人用, 而不是卖配方"**
5. **"在创作领域 LLM 智力是低质量的, 价值在链路串联"**
