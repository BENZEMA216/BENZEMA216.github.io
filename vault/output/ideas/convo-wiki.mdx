# convo-wiki 记忆编译器

> 从 04-08 晚开始, 4 版迭代, 从 "提取知识" pivot 到 "提取人的注意力"。

---

## 核心命题

用户跟 AI 的所有对话散落在 6 个工具 + 5 个 vault 里, 没有一处能给出完整视图。 一个 background agent 自动把所有对话编译成第一人称叙事, 提取 decision / try / milestone / aha / open-loop / position / work。

## 关键 insight

1. **人的记忆和 Agent 的记忆是两套系统** — Agent 记住信息, 人记住反应
2. **大部分 "我决定" 是 try, 不是 commitment** — 诚实比数量重要
3. **用户自己都忘了几小时前的讨论** — 这是产品的核心价值 (memory amnesia)
