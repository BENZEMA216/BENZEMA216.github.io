# Rent-ops 中国租房 AI Skill

> 04-09 一天内从发现痛点到 decide 要 build 到底。

---

## 核心命题

中国租房信息极度分散 (链家/贝壳/58/小红书/豆瓣/闲鱼...), 没有一个工具能跨平台聚合 + 去重 + 风险检测。 做一个 Claude skill 自动化这件事。

## 关键 aha

1. **"去重不能靠模糊地址匹配, 要靠 ID 级证据"** — 同一套房不同平台发布 ID 不同, 但照片 hash / 房东电话 / 精确面积是 hard identifier
2. **"风险检测是假命题, 真正的风险信息在小红书避雷贴里"** — 不是分析合同, 是搜社区口碑
3. **"中国租房信息分散到这种程度让自己也感叹"** — 亲身痛点

## 状态

- decision: "做 rent-ops 并 build 到底"
- spec 已修正 (去重 + 风险模块按中国市场现实调整)

## 定位

自用工具 → 开源 skill → 可能 SaaS 化
