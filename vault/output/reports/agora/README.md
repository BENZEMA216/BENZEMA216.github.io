## 维护规则

1. Combo 当前材料进入 `output/reports/combo/`；Agora 长期机制与历史研究继续保留在本文件夹。
2. 新对外材料 → 判断属于哪个模块 → 更新对应 README / map + [_summaries](/wiki/_summaries/) + [log](/wiki/log/)。
3. 历史文件不机械改名或删除，用 `status / status_reviewed / evidence_level / superseded_by` 标明状态：`supporting` = 仍可使用的研究或机制参考；`historical` = 已退出当前路线的探索；`superseded` = 已被新真源替代；`future-thesis` = 仅在条件满足后讨论的长期命题。`current` 只用于 Combo 当前材料。`status_reviewed` 只表示分类审阅日期，不代表旧报告的外部事实已在该日重新核验。
4. 链接在 basename 唯一时用 `[[basename]]`；若存在重名，必须用 `[[path/to/file|显示名]]` 消歧。
5. 纯领域研究（world-model / richard-chien / harness / OASIS 等）继续留在 `output/reports/` 根目录与 [知识库领域索引](/wiki/_index/)。
