中国竞品深度报告：Agent/Skill 能力商品化与创作者变现——谁在做、为什么（不）成立

调研主题：Agora 解决“为什么 Skill/Agent 能力创作者赚不到钱”。三层根因——L1 价值捕获（能力可无限复制→无产权→无定价）、L2 市场触达（agent 用户漏斗窄）、L3 价值证明（买家付钱前无法预判有用，binding constraint）。本报告核实了 40+ 中国玩家，并对 2026 上半年（知识截止 2026-01 之后）的关键动态做了 web 一手核实。

1. 执行摘要

一句话判断：在中国，“第三方创作者把 Agent/Skill 能力做成商品、用户付现金、平台逐笔分账”这件事，只有字节扣子（Coze 2.0 技能商店/付费模板）一家在 Agent/Skill 这个原子单位上真正跑通了“用户付费现金分账”；其余绝大多数玩家要么是“平台积分/流量补贴冒充分成”，要么是“广告/带货/线索的间接变现”，要么是“卖席位/卖项目的 B 端 SaaS”，要么干脆只做免费开源目录——整条赛道的 L1（产权/定价）和 L3（买前价值证明）系统性空白。

3-5 条要点：

  1. “现金 vs 积分”的诚实区分后，真 yes-cash 的极少。 在能力商品化方向上，真正让第三方拿到“终端用户付费现金”的只有：扣子技能商店/付费模板（Agent/Skill 层，2026-01 起）、支付宝 AI收/AI打赏（结算轨，2026 上半年）、钉钉/飞书/百度千帆应用商店（但卖的是传统 SaaS/企业应用，不是 Skill）、阿里云云市场（重型 ISV 软件，MCP 刚开始进入）。LiblibAI/SeaArt 的“现金”是平台奖金池按流量补贴（介于 cash 和 points 之间），不是逐笔用户付费分账。

  2. 大厂的“帮开发者赚钱”普遍是流量变现，不是能力定价。 百度文心智能体平台喊得最响（“有钱赚”“帮 10 万+ 智能体赚钱”），但核实后全是联盟广告分成 + 电商带货 CPS + 线索 CPA——钱来自广告主/商家，智能体只是百度搜索生态里的流量漏斗，能力本身从未被定价。这恰恰反证 L1：能力不被定价，只能靠把流量变现。

  3. 中国所有 coding agent 的“MCP 市场”本质都接到公益开源注册表上，零现金变现。 字节 Trae、腾讯 CodeBuddy、百度 Comate、智谱 CodeGeeX、阿里 Qoder CN 的 MCP 市场，上游都是魔搭 ModelScope MCP 广场（自我定位“公益、非营利、中立、全部开源”）、Higress、火山引擎 MCP Market。结构上排除了创作者现金变现。CodeBuddy 把“分发+沙箱执行+授权弹框”做到位了，恰好缺 Agora 要做的 L1+L3。

  4. 2026 上半年最大的真实变化是支付宝把“现金结算轨”开放了，而不是大厂上线了分成 marketplace。 阿里 Agent Store 上线了但只是模板库（一键复制配置），不是挂牌分成市场；真正补齐 L1“支付/结算”原语的是支付宝 AI收（2026-04-28 上线，按调用即时收款，个人开发者 0 费率至 2026-12-31）+ AI打赏（2025-06）。这是“现金轨”开放，不是“能力市场”成型——产权/定价/价值证明仍空白。

  5. B 端 SaaS 分账是中国唯一被验证规模化跑通的真现金路径，但它不是 Skill/Agent 创作者市场。 钉钉（1:9 分成、佣金降到 15%）、阿里云云市场（5%/10% take-rate）、百度千帆应用商店（最低 10% 抽佣）都有真现金分账闭环——但卖的是企业级成品应用/解决方案，买家是 B 端企业，入驻主体是企业 ISV，与“个人把一个 Skill 即买即用卖给海量用户”的靶心错位。

3. 关键洞察：中国与西方的结构性差异

(1) 生态分发 vs 独立 marketplace——中国根本没有“中立市场”这一物种。 西方有 App Store/Stripe Connect/PromptBase 这种“中立平台对能力收钱→统一现金分账”的范式。中国的“市场”几乎全部寄生在超级 App 生态里：扣子寄生抖音/飞书、元器寄生微信/QQ、百度寄生搜索、钉钉/飞书寄生办公租户。结果是分发护城河 = 渠道流量，而不是能力变现机制本身；平台锁定强、能力不可跨 runtime 携带。这制造了 Agora 的核心机会窗口：跨平台可携带的能力产权层在中国是真空。

(2) C 端付费意愿极低，逼出“免费+生态分发+B 端/会员打包”逻辑。 剪映 SVIP 半年付费转化率仅 3.2%；豆包约 3.45 亿 MAU 但几乎全免费；中国 C 端订阅天花板低。36氪地面真相直言“国内 C 端用户对工具类智能体付费意愿低”。这决定了中国能力商品化若走 C 端订阅必死，真正跑通现金的全在 B 端（钉钉/云市场/千帆/用友）或内容素材层（剪映/LiblibAI）。

(3) “创作者激励”是最大的伪装陷阱——必须逐个戳穿。 本次核实最重要的方法论收获：中国平台高频用“创作者激励/收益分成”话术，但 95% 是平台发的流量补贴/积分/算力券/奖金池，不是用户付费的现金分账。已戳穿的：百度文心“感谢激励”=平台积分；魔搭/360/星流=积分/补贴；SeaArt/LiblibAI=平台奖金池（介于两者之间）；扣子技能大赛奖品=实物。只有扣子技能商店/付费模板（个税代扣坐实）、剪映付费解锁（官方不分佣、用户直付）、阿里云市场（take-rate）、支付宝 AI收（按次现金）是干净的 yes-cash。

(4) 大厂吞并风险被高估，“现金轨开放”才是真信号。 KB 曾把阿里 AI Agent Store 列为“吞掉独立开发者 marketplace 空白”的最大威胁——核实后证伪：Agent Store 只是模板库，不是分成市场。阿里真正做的是让支付宝把“现金结算原语”开放（AI收 0 费率拉拢个人开发者）。这意味着大厂的姿态是“补支付/结算基建”，而不是“自己下场做能力挂牌市场”——对 Agora 是机会大于威胁（基建被补齐，可以站在支付宝/微信支付的现金轨上做产权+价值证明层）。

(5) B 端 SaaS 分账是中国唯一规模化验证的真现金路径，但它不是 Skill 创作者市场。 钉钉（1:9）、阿里云市场（5%/10%）、千帆商店（10%）、用友 YonStore 都跑通了真现金分账——但全是企业级成品应用、买家是 B 端、入驻是企业 ISV。这既证明“take-rate 现金分账在中国技术/合规可行”，又暴露了空白：没有一家把它降维到“个人创作者把一个低客单 Skill 即买即用卖给海量用户”的形态。

5. 对 Agora 的含义

5.1 中国这条线上“创作者真现金变现 + 可验证交付(L3)“的空白在哪

空白一：L1 的“可携带产权 + 逐笔 entitlement 分账账本”。 中国跑通的现金分账要么锁在围墙内（扣子=Coze runtime、钉钉=企业租户、剪映=视频素材），要么是平台奖金池按流量补贴（SeaArt/LiblibAI），要么是 take-rate 但只对企业 ISV（云市场/千帆）。没有任何一家提供“能力可跨平台/跨 runtime 携带、被外部主 agent/orchestrator 当作可计费商品调用组合”的产权层。 这正是 Agora 的 entitlement + event ledger 主张的真空。

空白二：L3 价值证明是全行业的 binding constraint，无人专门攻。 所有玩家在“买家付费前预判能力是否有用”这件事上都是空的——扣子只给 3 个案例/复制数/榜单，SeaArt/百度用事后流量数据，钉钉/用友靠 ISV 行业背书+人工对接。没有人做“试用即退/按效果计费/canonical tests/失败归因/compatibility matrix”。 Skill 赛道实证（Smithery $208）证明：没有 L3，即便挂上价格也无人买。 这是 Agora 最该攻、对手最空的层。

空白三：低门槛、自助、海量低客单的 Skill/Agent 商品形态。 B 端 SaaS 分账验证了现金可行，但买家“买席位不买能力”、入驻“要企业资质”、交付“要项目对接”。“个人创作者把一个低客单能力即买即用卖给海量终端用户”的形态在中国是确凿空白。

5.2 阿里 AI Agent Store / 扣子等大厂动作：机会还是威胁

机会大于威胁，但威胁集中在一家——扣子。

  • 阿里：机会。 Agent Store 是模板库不是分成市场；阿里的真正贡献是支付宝把现金结算轨开放了（AI收按次现金、个人 0 费率）。Agora 可以站在支付宝/微信支付的现金轨之上做产权+价值证明层，不必自建支付。阿里补的是 L1 的“支付/结算”子项，留出的正是“产权/定价/L3”。

  • 扣子：唯一实质威胁，但缺口清晰可狙击。 扣子是中国唯一把“第三方把能力做成商品+真现金分账+提现+个税合规”全链路跑通的玩家（L1 形态对了）。但它：(1) L1 不可携带——锁死在 Coze runtime，能力一旦复制/搬出即失捕获；(2) L3 极弱——只有 3 个案例的事前展示，无效果担保/试用即退/按效果计费/失败归因；(3) 付费资格部分 gated 于官方活动，原生支付历史上覆盖不全（逼创作者退回微信收款码/第三方封装）。Agora 的差异化正好对位扣子的三个缺口：跨平台可携带的能力产权层 + 可验证效果的 L3 entitlement + 不依赖单一平台流量的中立分发。

  • 钉钉：B 端最强对手 + 最值得借鉴范本，但 AI 层未坐实。 钉钉软件 ISV 现金分账最成熟（1:9），但 AI 助理层“按结果付费”无真实成交、第三方 AI 服务无专属分账条款、能力锁租户内不可携带。Agora 在 B 端的差异化机会就是补 L1 携带性 + L3 标准化价值证明这两个钉钉没做的层。

净结论：中国这条线上，真正的护城河不在“再做一个目录/商店”（那已被大厂用流量碾压），而在 Agora 主张的 L1（可携带能力产权 + 逐笔现金分账账本）+ L3（买前可验证交付）。大厂正在替 Agora 补齐支付结算基建（支付宝 AI收/微信支付 MCP），却系统性地回避了产权携带性与效果证明——这两个层，是中国 40+ 玩家逐一核实后，唯一一致的、确凿的空白。
