国内产品型创业 第一笔融资 深度研究

国内产品型创业 第一笔融资 深度研究

来源: 知识库 Query 讨论 (2026-04-07) 调研方法: 3 路并行 subagent（融资渠道全景 + 奇绩创坛专题 + 2026 真实案例） 目标用户: Dongzhe，产品经理 + Agent 研究深度 + 已部署 Wiki MCP Server + 考虑赴港 + 可能 solo 或拉 co-founder

TL;DR（3 个核心判断）

  1. 2026 不是融资寒冬，是分化年：AI infra 在降温，AI 应用层 2025 单年融了 ¥1070 亿、930 家公司、日均 2.6 家拿钱。产品型 AI 创业者反而是红利最大的一侧。

  2. Super-Individual 已经是 2026 的正规叙事：陈天桥 24 小时给 MiroFish ¥3000 万、Base44 6 个月零融资被 Wix 以 $80M 收购、美国 2025 H1 单人创始公司占比 46.3%。vibe coding 把“1 个人 6 个月做出 PMF”变成常态，第一笔钱的逻辑正在被改写。

  3. 对你最现实的融资序列是：Bootstrapped 3 个月 → 奇绩创坛 → 个人天使（陈天桥 / 王慧文 / 朱啸虎个人）。跳过亲友股权钱，保持 cap table 干净；用 Wiki MCP Server 作为“可演示资产”而不是空想 thesis。

🟠 TIER 4: 亲友轮（只走借款，避免股权）

两种合法路径:

形式 特点 风险
借款（推荐） 固定本金 + 利息 4-8%，不参与经营 低，但必须签《借款合同》明确条款
股权投资 参与盈亏，签《投资协议》 高，cap table 变乱

三条致命红线:

  • ❌ 不要平分股权（50/50 或 33/33/33 是最不稳定结构，最高法多次判例）
  • ❌ 不要拿超过 ~30 个亲友的钱（可能触发“非法集资”刑事红线）
  • ❌ 不要没签书面协议（法院按合伙处理，亏了要赔）

建议: 只走“借款”路径，不让亲友持股，保持 cap table 干净进入奇绩/VC。

  • 价值排序：曝光 > 媒体 > 投资人 connection > 奖金本身
  • 核心用法：拿 demo day 曝光，不是为了奖金

四、MiroFish 为什么能 24 小时融到？（解构 anomaly）

4 个独立低概率事件的乘积:

  1. 冷启动 = 全球可见的客观信号：GitHub Trending #1，几天 20k★。投资人无法 fake 的“市场已投票”信号，省去尽调全流程
  2. 作品 + 创始人故事高度耦合：20 岁、大四、10 天 vibe coding、做红楼梦后 40 回——一个 narrative 三个梗
  3. 陈天桥这类 super-LP 绕开 IC 流程：他不需要合伙人会议，要的就是“first call rights on solo viral founders”
  4. 方向命中个人 thesis：multi-agent + 群体智能 + 脑科学外溢，正好是天桥脑科学研究院主线
  5. “deep incubation”而非纯股权交易：估值条款模糊，速度优先

可复制性低，但启示意义高：vibe coding 时代的核心货币 = “可被截屏的客观市场信号 + 一句话讲完的 founder story”。Demo / ARR 截图 / GitHub 星标 / Twitter 病毒都是同一种东西。

五、典型融资时间线

标准 VC 流程（3-5 个月）

决定融资 → 准备 deck/demo    : 1-2 周
Outreach → 首次见面          : 2-4 周
多轮会谈 → 第一份 TS         : 3-6 周
TS → SPA → 工商变更          : 4-8 周
工商变更 → 资金到账          : 1-4 周
总计                         : 3-5 个月

个人天使 / 超角色流程（24h - 2 周）

陈天桥模式：看 GitHub 数据 + demo video → 24h 打款
王慧文模式：个人 LP 出资 → 1-2 周

奇绩创坛流程（固定 batch）

申请开放          : 常年
截止             : 12 月底（延期可）
初筛             : 12 月-2 月
面试             : 3-6 月
创业营           : 3-6 月（或 9-12 月）
Demo Day         : 6 月 / 12 月
Demo Day 后 3 天 : 40%+ 团队拿到下一轮 TS

六、对 Dongzhe 的推荐：三条现实路径

你的资产盘点

  • ✅ 正资产：产品能力 + Agent 经济垂直研究 + 已在线的 Wiki MCP Server + BENZEMA216 个人品牌
  • ⚠️ 缺口：病毒时刻 / 大厂 title 光环 / 已成交的 ARR

路径 A：奇绩创坛通道（最高确定性）⭐

流程:

  1. 提交 Wiki MCP Server demo + Agent 经济 thesis
  2. 12 个月“平台层而非工具层”的愿景
  3. $30 万 +7%，3 个月加速
  4. Demo Day 直接对接红杉 / 真格 / 五源

估值: 投后约 ¥3000 万（$4.3M）

优势:

  • 不需要病毒时刻
  • 最稳确定性路径
  • 对 solo founder 友好
  • 香港 relocation 不冲突

劣势: 估值最低

路径 B：MiroFish-Style 病毒杠杆（高方差）

流程:

  1. 不要直接融资
  2. 用 6-10 周做一个“小而锋利”的开源工件
  3. 复用 MCP 经验：比如 “agent 经济 indexer” / “MCP 服务器市场” / “agent-to-agent 计价 demo”
  4. 病毒发生后，同一周联系：
    • 陈天桥（盛大投资邮箱 / Tanka 团队）
    • 王慧文（美团校友通道）
    • 投资界 / 36Kr 编辑制造二次传播

预期:

  • GitHub 5k★+ → $1-3M 个人天使快闪轮
  • 1k★ 以下 → 回到路径 A

核心: 你已经有 wiki-mcp-server 这个 foundation 了，现在要的是“杠杆点”。

路径 C：Thesis 投资人（中等确定性）

目标机构（对“早期 AI infra/Agent 平台”愿意听 vision）:

  • 真格基金（Manus 验证过的通道）
  • 锦秋基金（乐享科技领投经验）
  • 线性资本 Bolt 计划（决策极快）

打法:

  • 把“Agent 经济变现”thesis 包装成融资素材
  • 第一页就是 Wiki MCP Server 真实数据 + 增长曲线
  • Deck 第二页是 RC / Claude Code / OneBot 协议层对比

预期: 天使轮 ¥1000-3000 万，投后 ¥1-2 亿

七、关键执行建议

立即可做（今晚 - 本周）

  1. 今晚: 填奇绩创坛 2026 春季延期申请（常年开放，无机会成本）
  2. 本周: 准备 30 秒 demo video（陆奇公开说过“看视频比看 BP 多”）
  3. 本周: 给陆奇 / 奇绩合伙人写一封 cold email，引用“Agent 经济变现基础设施”的核心论点

本月可做

  1. YC F26 并行申请（两份材料 80% 可复用）
  2. 试一次 MiroFish-style 病毒尝试：用 vibe coding 做一个能上 GitHub Trending 的小工件
  3. 注册落户深圳 + 领人才补贴（现金流补丁）

绝对不要做

  • ❌ 现在直接跑 VC 流程：对没有病毒时刻 + 没 ARR 的纯产品型创始人成功率极低
  • ❌ 接亲友股权钱：股权稀释陷阱 + cap table 后患
  • ❌ 签对赌 / 回购协议：罗永浩案例被迫回购 ¥1000 万+、山东瀚霖 14 亿打水漂
  • ❌ 平分股权 50/50 或 33/33/33：最高法/律所一致认定为最不稳定结构
  • ❌ 天使轮就出让 >25%：A 轮稀释后创始人 <50%，董事会失控
  • ❌ 没有客观信号前接触红杉/IDG/高瓴：会“礼貌性见面”然后归档 18 个月
  • ❌ 把“我懂 Agent 经济”当 USP：VC 已免疫，必须有产品/数据/star 背书
  • ❌ 朱啸虎现在的标准是 3 个月 $200 万 ARR，没有 ARR 不要敲他的门

首轮目标锚点

建议首轮: ¥500-1500 万 + 投后 ¥5000 万-¥1.2 亿

  • 不会贱卖
  • 不会把后续轮次门槛拉太高
  • 给你 18 个月的 runway
  • 保留 >60% 创始人股权（含期权池）进 A 轮

八、2026 特有环境总结

不是寒冬，是分化年

冰:

  • AI infra/算力层估值警报（寒武纪 P/E 71 vs Nvidia 46）
  • 全球 AI ARR ~$3000 亿 vs 需要 $6 万亿才合理 → infra 泡沫

火:

  • AI 应用层 2025 共 ¥1070 亿融资
  • 930 家公司，日均 2.6 家拿钱
  • 2026 被定位为“AI 应用从验证走向规模商业化的关键年”

Super-Individual 趋势（产品型最大红利）

  • 美国 2025 H1 单人创始公司占比 46.3%（历史峰值）
  • 国内陈天桥等天使明确押“超级个体”叙事
  • 大四学生 10 天 vibe code + 24 小时 ¥3000 万 = 新模板
  • 隐含条件: 必须有“病毒式可传播的 demo + GitHub/X 上的公开数据”

Vibe Coding 改变游戏规则

九、关于香港赴港的融资影响

正面

  • HKSTP Incubation Programme: 最高 HK$1.29M（约 US$165K）非股权型
  • HKSTP × AWS AI Co-incubation（2025 新启）: AI-first, Seed-A 阶段
  • Cyberport: HK$500K 非股权，偏 Fintech
  • HK AI Innovation Fund: HK$10B 政府基金
  • 落户补贴 + 税率优势（利得税 16.5% 两级制）

负面

  • 奇绩入营必须能去北京 3 个月（香港只是宣传/面试节点）
  • 国内主流 VC 对港注册公司尽调更麻烦
  • 人脉/曝光远不如北京/深圳

权衡

  • 创业早期: 北京/深圳 > 香港（奇绩 + 真格 + 陈天桥都在 mainland）
  • 规模化后: 香港 > 大陆（税率 + 国际市场 + 资金出入）
  • 折中方案: 北京注册 + 香港研发中心 + 未来移架构

十、最终总结：一句话

第一笔钱不是目标，第一个 unfair advantage 才是。你的 unfair advantage 是 agent-friendly 设计 + 已有 Agent 研究资产 + 在线的 Wiki MCP Server。2026 是 agent-as-product 元年，估值溢价存在。在这个窗口里，奇绩创坛 + 一次 MiroFish-style 病毒尝试 + 陈天桥/王慧文的个人天使通道是最符合你资产的融资路径。绝对不要在没有客观信号前直接跑 VC 流程。
