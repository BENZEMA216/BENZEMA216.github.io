# 本溯智能（Basal）核心论文与作者贡献审计

> 结论：BP 不是虚构论文，但把“公司核心成员主导成果、清华 AIR-DREAM Lab 历史成果、Workshop 论文、在投论文”混成了一个 40+/60+ 篇的总数。按“当前核心成员为第一/共同第一/Project Lead，且论文已被正式主会接收”的严格口径，最值得归入公司核心学术资产的是 **X-VLA、UniAct、LBP、IVM、Robo-MUTUAL**；FISOR、DIPOLE 属于强能力佐证；DecisionNCE 对技术路线重要，但只是 ICML Workshop 优秀论文；ODEWorld、WVM 尚不能计入已兑现学术成果。

## 一、审计口径

### 什么算团队真正做的

| 级别 | 作者贡献与论文状态 | 本报告处理 |
|---|---|---|
| A | 当前核心成员为第一/共同第一或明确 Project Lead；正式主会接收 | 公司核心学术成果 |
| B | 当前核心成员为共同第一，首席科学家为通讯作者；正式主会接收 | 核心成果，但须确认该成员已经全职加入及 IP 归属 |
| C | 当前成员只是中间作者，或只有首席科学家通讯、第一作者未加入公司 | 实验室/合作成果，不作为公司独立研发能力的核心证据 |
| D | Workshop、arXiv、在投论文 | 单列，不获得正式主会同等学术信用 |
| E | BP 中只有名称或性能口号，无公开论文、作者表及评审结果 | 暂不采信 |

共同第一作者通常足以证明实质研究贡献；Project Lead 是更强证据。通讯作者通常证明课题设计、指导或资源责任，但不能单独证明由公司执行团队完成。中间作者不能自动视作挂名，但也不足以支持“该成员主导该成果”。

## 三、按综合含金量排序

这里的“含金量”不是只看会议名，而是同时考虑：正式接收质量、作者贡献强度、与公司技术路线的直接关系、是否由当前执行团队主导。

### 第一梯队：应该先精读

1. **X-VLA — ICLR 2026**
   - 目前最完整的公司技术名片：跨本体、VLA、真实机器人、连续长任务。
   - CEO 和模型预训练负责人共同一作，首席科学家通讯，团队归属最清晰。
   - 也是判断“比赛冠军是否能迁移为通用产品能力”的最佳入口。

2. **UniAct — CVPR 2025**
   - CEO 是共同一作兼 Project Lead，作者贡献证据最硬。
   - 直接支撑公司最有辨识度的主张：用通用动作 token 连接不同机器人本体。
   - 需要重点检查离散动作码本的信息损失、跨本体扩展方式以及是否真的能形成可控接口。

3. **LBP — ICML 2025**
   - 正式顶会，直接讨论 latent-space planning 和样本效率，比单纯视觉表征更接近公司的“世界模型/决策建模”路线。
   - 但公司归属取决于 Haoyi Niu 是否就是 BP 中的 `YI`、是否全职加入及相关 IP 是否完成转让。

4. **IVM — NeurIPS 2024**
   - CEO 与模型负责人共同一作，团队贡献明确。
   - 是 DecisionNCE 到 UniAct/X-VLA 之间的重要表征学习节点，可检验所谓“小样本、高泛化”的真实来源。

5. **Robo-MUTUAL — ICRA 2025**
   - CEO 共同一作兼 Project Lead，贡献明确；任务 specification 与用户自定义机器能力高度相关。
   - 学术 venue 不弱，但更适合被视为系统/机器人能力论文，而非通用基础模型已经成立的证据。

### 第二梯队：证明专项能力，不宜包装成公司核心基座

6. **FISOR — ICLR 2024**：证明安全 Offline RL 与后训练能力；与当前 VLA 主产品距离较远。
7. **DIPOLE — ICLR 2026**：证明 diffusion policy optimization 能力；公司归属仍依赖 Yinan 的全职/IP。
8. **Diffusion Planner — ICLR 2025 Oral**：单看学术 recognition 很强，但场景是自动驾驶，不能直接外推机器人操作。
9. **DecisionNCE — ICML 2024 Workshop Outstanding Paper**：概念谱系重要、作者贡献真实，但不能与 ICLR/NeurIPS/ICML 主会论文按同档计分。

### 暂不进入排名

- **ODEWorld**：无可公开核验稿件，且仅为 NeurIPS 2026 submission。
- **WVM**：CoRL 2026 submission/arXiv，尚未接收，作者贡献也不是现有核心团队明确主导。
- BP 的 **“60+ 论文 / 40+ 顶会论文”**：这是实验室和成员历史 portfolio，不等于公司共同完成或公司拥有的 60 项 IP。
- RL 长列表中仅由詹仙园担任通讯作者、第一作者未加入公司的论文：可证明首席科学家的研究组织能力，不应算作公司执行团队的原创产出。

## 五、接下来怎么读

建议按以下顺序做论文级技术尽调：

1. **X-VLA**：先判断其“跨本体”到底是统一模型、统一数据接口，还是不同本体上的参数高效适配；拆解 benchmark、对照组、训练数据和真机失败案例。
2. **UniAct**：检查动作 tokenizer 的训练目标、跨本体共享程度、码本可解释性、压缩率与控制精度之间的代价。
3. **LBP**：判断 latent backward planning 是否真的提供世界模型能力，还是一种 goal-conditioned policy learning 技巧。
4. **IVM + DecisionNCE**：追踪团队从时序进度表征、视觉表征走到动作建模的连续性，核实“20 分钟数据、成功率 >50%、鲁棒性 +60%”分别来自哪些实验和基线。
5. **Robo-MUTUAL**：评估自然语言/图像/视频 specification 是否能迁移到新任务，及真实用户纠错成本。
