# Basal 具身智能团队评估

> 生成时间：2026-07-22
> 查询：Basal 是一个什么样的团队，如何评价；核验其融资、模型、比赛、开源与团队主张

## 摘要

Basal 更准确的定位是：**由清华 AIR-DREAM 核心研究成员外溢形成、以 data-efficient / cross-embodiment robot learning 为技术主线，并试图向软硬一体机器人公司迁移的早期团队**。它不是缺乏技术资产的融资包装：DecisionNCE、IVM、UniAct、X-VLA 构成了连续研究谱系，X-VLA 已被 ICLR 2026 接收、开源并获得 IROS 2025 AgiBot World Challenge Manipulation Track 第一名。

但“研究团队很强”不等于“公司壁垒已经成立”。截至查询，公开证据尚不足以独立确认公司主体、800 万美元天使轮、ODEWorld、50 万+ Hugging Face 下载、硬件 0→1 指标和客户/收入。投资判断应是：**技术团队 A-/A，研究连续性 A，开源与竞赛验证 A-，公司化与 IP 边界待核，硬件/量产 C?，商业验证 D?/未披露；适合进入深度尽调，不适合仅凭材料直接下结论。**

## 一、它是什么样的团队

它不是传统机器人本体公司，也不是只做一个 end-to-end VLA 的单点模型团队。公开成果显示其主线是把机器人学习拆成几类瓶颈并分别优化：

| 层 | 公开成果 | 实际解决的问题 | 证据状态 |
|---|---|---|---|
| 任务相关表征 | DecisionNCE | 从视频轨迹学习任务进度、时序一致性与语言对齐 | ICML 2024；论文/代码公开 |
| 视觉 grounding | IVM | 屏蔽与指令无关的视觉区域，提高复杂场景下的决策鲁棒性 | NeurIPS 2024；论文/代码/数据公开 |
| 动作表示 | UniAct | 将不同机器人 action space 映射为 tokenized universal action space | CVPR 2025；论文/代码公开 |
| 跨本体策略 | X-VLA | 用 embodiment-specific soft prompts 训练统一 VLA，并低成本适配新本体 | ICLR 2026；代码/checkpoint 公开；比赛冠军 |
| 世界模型 | ODEWorld | 宣称以连续时间 latent dynamics 做物理推演 | 未检索到可归属该团队的公开论文/代码，待 data room |
| 硬件 | 自研机械、电气、运控、OS | 宣称形成本体闭环和快速迭代 | 只有团队履历支持“有能力”，缺产品、BOM、测试和交付证据 |

这条研究谱系有内在一致性：不是随机堆论文，而是围绕“机器人数据少、视觉干扰大、不同本体动作空间不统一、模型迁移成本高”逐层解决问题。所谓“配置器+感知器+世界模型+记忆+动作+价值评估”更像公司的**目标架构**，不能当作六模块已集成、已在同一闭环中验证的事实。

## 二、已经被公开证据确认的部分

### 1. X-VLA 是最硬的资产

- X-VLA 为 0.9B flow-matching VLA，以每个数据源/本体的 learnable soft prompt 吸收异构性；论文覆盖 6 个 simulation setups 和 3 种 real-world robots，并被 ICLR 2026 接收。
- IROS 2025 官方赛事与赛后公开信息确认：AIR-DREAM 获 Manipulation Track 第一名；不能泛化表述为两个赛道的“总冠军”，World Model Track 第一名是中科院 VIPL-GENUN。
- GitHub `2toinf/X-VLA` 截至 2026-07-22 为 693 stars、67 forks、Apache-2.0，且包含安装、推理、LoRA 与多 benchmark checkpoints。这是可运行工程资产，不只是论文主页。
- “性能击败 Pi0/Pi0.5”只能限定在论文选择的 benchmark、模型版本、数据与 evaluation protocol 下表达。它证明 X-VLA 在若干公开任务上有竞争力，不证明通用机器人能力全面超过 Physical Intelligence。

### 2. UniAct、DecisionNCE、IVM 构成连续研究能力

- UniAct 将不同本体动作压缩到 universal action tokens，0.5B 实例在论文实验中优于更大模型；它提供了跨本体迁移的有价值接口。
- 但“把黑盒暴露成白盒，人类可通过码本直接纠偏”是对可解释性的强化营销。离散码本可以被观察、聚类和替换，不自动等于 token 语义稳定、因果可解释或人工纠偏安全。
- DecisionNCE 和 IVM 说明团队在“表征/奖励”和“任务相关视觉过滤”上不只会 scale model；IVM 为 NeurIPS 2024 正式论文，DecisionNCE 为 ICML 2024 论文并与 IVM 获同一 workshop outstanding paper。

### 3. 团队履历基本真实，但材料有角色和口径放大

- 李健雄公开主页显示其聚焦 embodied AI / RL，是 X-VLA、UniAct、DecisionNCE、IVM 等工作的核心/共同作者；“20+ 论文、1000+ 引用、千万级 offer”中，论文可逐项核验，引用数会漂移，offer 无法由公开资料确认。
- 詹仙园公开履历确认清华 AIR 副研究员/副教授、AIR-DREAM Lab 负责人、80+ 论文、微软亚研/京东经历及工业控制落地。材料中的“上海 AI Lab 研究员”需要确认当前雇佣/兼职关系。
- 尹建华的北理工官方页确认普渡机械工程博士、北京理工预聘副教授；“密歇根博后、国家级青年人才、40+ 论文、全栈硬件能力”应要求简历、人才项目批文和具体机器人项目验收材料。

## 四、技术上怎么评价

### 最强处

1. **研究主线连续且非跟风。** 从 representation → grounding → universal action → cross-embodiment VLA，问题选择彼此衔接。
2. **data efficiency 与 cross-embodiment 是有价值的楔子。** 中国创业公司很难在通用机器人数据和算力上正面复制 π、Skild、Google；用小模型、软提示、动作 tokenization 降低适配成本，是更现实的非对称打法。
3. **算法、真机、赛事和开源四种证据同时存在。** 比只在 simulation 或只发视频的团队更扎实。
4. **决策/RL 背景有差异化。** 团队不是单纯把 VLM 接动作头，而是长期研究表征、reward、planning 与 control。

### 最大技术风险

1. **模块组合不等于 foundation model。** 六个模块是否 joint training、共享 latent state、统一 objective、支持 online correction，目前无公开系统证据。
2. **benchmark SOTA 到开放世界可靠性有巨大鸿沟。** 真正难点包括长时程误差累积、接触/柔性物体、OOD scene、硬件磨损、失败恢复和安全停机。
3. **soft prompt 可能隔离本体，而非真正形成统一物理表征。** 新机器人仍要多少数据、是否负迁移、prompt 是否随传感器/控制频率变化，是关键。
4. **世界模型是材料里最激进、证据最弱的一层。** 在公开 ODEWorld 证据出现前，不应把它计入估值核心资产。

## 五、公司与投资上怎么评价

这是一个典型的**“强 academic founder-market fit，弱 commercial proof”**项目。

- 若公司选择卖“通用具身基础模型”，会正面遭遇数据、算力、客户自研、开源替代和大厂平台挤压，商业化很难。
- 若选择软硬全栈做人形/通用本体，资金密度、供应链、可靠性、售后与场景落地会吞噬算法优势；800 万美元只够完成关键验证，不足以证明规模化。
- 更可信的切入点是一个高价值、可量化、需要跨本体迁移的 manipulation 场景，把 X-VLA/UniAct 变成**适配速度、成功率、恢复率和部署成本优势**，再逐步扩展平台。
- 真正护城河不会是论文列表，而是：跨客户/本体的授权数据、同一模型的 deployment base、失败恢复数据、硬件遥测、快速适配工具链、长期现场 uptime，以及模型/硬件的 IP 清晰归属。

## 六、建议的尽调问题与投资闸门

### P0：会改变是否投资

1. 公司法定主体、cap table、800 万美元是已到账/已签/目标募资；投资方、估值、交割条件。
2. 三位核心成员是否全职；高校/上海 AI Lab/原合作方对论文代码、checkpoint、数据、专利和后续成果的权属。
3. 现场盲测一个训练分布外任务：不剪辑，记录成功率、人工接管、恢复、单任务适配数据量和总时长。
4. ODEWorld 的论文、代码、完整 benchmark 与 inference profile；若无法提供，估值中归零。
5. 至少一个付费客户/联合开发客户：谁付钱、为何购买、验收指标、部署周期、毛利和续约路径。

### P1：验证能否从好研究变成好公司

- 新本体适配需要多少 demos / GPU hours / 工程人周；与 π0.5、OpenVLA、Octo、GR00T 等在同一数据和硬件下比较。
- 过去 6 个月失败案例：哪些任务没学会、world model 在哪里漂移、何时需要人工接管。
- 硬件版本、BOM 国产化比例、核心器件单一供应商、MTBF、重复定位/力控指标、交付与售后成本。
- 未来 18 个月资金分配是否对应可验收里程碑，而不是继续扩充论文模块。

## 最终判断

**值得认真见、值得做技术 DD，但暂不值得按“国内唯一全栈具身基础模型公司”叙事直接追高。**

最合理的正面 thesis 是：这是国内少见的、真正理解 robot learning 数据效率与跨本体问题、已经用论文+开源+比赛证明 execution 的年轻团队；如果核心成员全职、IP 清晰，并能在一个付费场景里把适配周期和部署成功率做成数量级优势，它可能从强实验室团队转化为有价值公司。

最主要的反面 thesis 是：材料把不同阶段、不同合作机构、不同 benchmark 的成果拼成“六模块全栈闭环”，同时对融资、世界模型、下载量、硬件指标和商业进展缺乏公开证据；最终可能是一支很强的研究团队，但没有形成公司专属资产和可复制收入。
