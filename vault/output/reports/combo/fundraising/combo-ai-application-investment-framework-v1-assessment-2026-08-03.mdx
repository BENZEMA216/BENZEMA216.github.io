## 结论卡

> **暂评分 55/100，合理区间 25–80；S0 探索期；证据覆盖率约 36%，置信度低；五项门槛中 0 项通过、2 项有条件通过、3 项待验证、0 项否决。当前建议：等待里程碑。**

这里的 `55` 不是“项目只有 55 分”，而是：Combo 的市场命题、团队匹配和已有工程使它不是纯概念项目，但第一笔可重复交易所需的需求、效果、产品、复购和单位经济证据尚未形成。`25–80` 的宽区间说明下一组真实订单足以大幅改变判断，因此本分数不能用于与其他项目排名。

如果投资人只做 **Pre-seed 团队与命题下注**，且估值、治理和资金用途合理，可以继续小成本尽调；如果投资依据是“创作者 AI 服务平台 / Marketplace 已经成立”，则当前不应推进。

## 四、投资评论

### 1. 项目本质和价值捕获

Combo 真正销售的不是 Agent、Prompt、Skill 或建站页面，而是一个有输入、承诺、价格、时限、验收和补救的专业结果。平台通过 Context 收集、AI + 真人履约、支付、退款与分账获取交易收入；如果订单持续留下服务版本、人工修改、结果与 Verdict，并降低下一单人工或提高成功率，才可能形成可复利的经营系统。

这比“Agent Marketplace”更可信，也更难：价值恰好位于通用模型没有自动解决的商品定义、信任迁移、质量验收和失败责任；但责任层也可能成为低毛利、高人工、高退款的负选择区。

### 2. 三项最强投资理由

1. **结构变化真实，商品原子比 Agent 更接近付款。** 通用认知与生成能力持续商品化，但专业服务的 scope、Context、验收、例外和责任仍未自动消失。Combo 从“具体结果”而非“智能能力”定义商品，方向是对的。
2. **不是纯 BP。** 本地代码审计确认能力提取、Capability、Studio、Runtime、版本和事件等相邻链路真实存在；团队也已把公司叙事从 Marketplace 收缩到单一垂类 Result SKU。
3. **冷启动路径可测试且资本效率较高。** 创作者已有内容、主页和私域可提供首批触达，不需要先建设公共 Feed；3–5 位创作者、一个垂类、一个结果合同就能快速产生方向级证据。

### 3. 三项最大风险 / 反证

1. **专业工作流痛点不等于粉丝购买。** 当前更强的一手信号来自创作者 / 专业团队工作流，但 Combo 需要证明独立买家愿意为一个结果额外点击、授权和付款，且不是熟人支持或人格消费。
2. **容易坠入“工具太薄、服务太重”的夹层。** 不承担结果责任会退化成可被模型平台、Kajabi 或支付页吸收的 Builder；承担责任又可能让人审、返工、客服和赔付随收入线性增长。
3. **护城河尚未开始运转。** OpenAI 已让 GPT 与 Skills 的创建、分享和调用越来越低门槛；Kajabi 已连接专家产品、营销、支付、交付和业务数据；Patreon 已提供创作者一次性商品交易。Combo 只有在“动态个性化结果 + 可托付履约 + 结果数据改善下一单”上显著优于这些基线，才是独立公司而非功能。

### 4. What must be true

值得投资至少需要以下五件事同时可行：

1. 某一类买家有自然发生、可重复且已有预算的任务，不需要 Combo 教育出需求；
2. 同一 Result SKU 相对裸通用模型具有可盲测的采用优势，同时比纯人工更便宜或更快；
3. 创作者愿意授权、上线、处理例外并持续更新，且获得足够有意义的净增量收入；
4. 计入退款、失败重跑、人审、支持、支付和分成后，代表性订单贡献毛利为正；
5. 增长不永远依赖创始人共创和 KOL 私域：先出现无创始人复制，再谈平台新增需求、跨创作者购买和路由飞轮。

## 五、情景判断

| 情景 | 会发生什么 | 公司形态 | 投资含义 |
|---|---|---|---|
| 谨慎 | 需求主要是尝鲜 / 熟人支持；通用模型已足够；创作者不愿维护；人工与退款吃掉抽成 | 项目制 AI 服务或薄 Builder | 暂不推进；停止当前 SKU，保留底层技术 |
| 基准 | 一个垂类有明确 SKU；至少两位创作者产生自然现金订单；质量优于通用模型；完整贡献为正；出现自然复购或下一任务 | 有价值的垂类创作者服务产品化工具 / Result OS | 可按 Pre-seed / Seed 工具与交易系统推进，不预付平台估值 |
| 乐观 | 多位创作者可无创始人上线；用户跨产品 / 创作者购买；Combo 带来新增需求；结果数据因果改善完成率、人工分钟或退款 | 垂直 Fulfillment System of Record，进一步获得交易网络期权 | 平台上行开始进入承保，而不再只是故事 |

最敏感的变量不是模型 Token 单价，而是：自然付费率、直通接受率、每单人工分钟、退款、30 日自然复购、创作者持续发布率，以及这些指标能否跨创作者复现。

## 六、改变结论的最低成本验证

### 未来 30–60 天只做一个投资实验

使用 [combo-one-vertical-validation-2026-07](/output/reports/combo/gtm/combo-one-vertical-validation-2026-07/) 已定义的“AI 视觉作品诊断与改进包”作为候选，但在开工前先用历史私信 / 订单证明任务频率。整个周期坚持：**一个垂类、一个 Result SKU、一套 rubric、一条真实资金链。**

1. **需求 Gate**：3–5 位创作者提交匿名化历史咨询 / 订单证据；若过去没有重复请求，不进入产品共创。
2. **效果 Gate**：对同一批真实输入盲测 `裸通用模型 / 创作者纯人工 / Combo AI + 真人`，预登记购买意愿、结果采纳、严重错误、返工和人工分钟。
3. **交易 Gate**：至少两位创作者从各自真实渠道带来非全额补贴的现金订单；连续订单不做成功案例挑选。
4. **经济 Gate**：逐单记录平台净收入、全可变成本、创作者到账、退款和共创工时；贡献为负时不扩量。
5. **重复 Gate**：等自然任务周期到达后再看 7/30 日复购、下一任务和第二产品；“尚未流失”不等于留存。

### 上调到 65–70 分并进入条件性推进

- 至少两位创作者产生真实现金订单，且不是熟人代购或平台全额补贴；
- 预登记盲测显示 Combo 在结果采纳 / 购买意愿上显著优于裸通用模型，严重错误可控；
- 代表性订单在完整成本下贡献为正，人工分钟随订单没有线性恶化；
- 出现自然复购、下一任务或创作者发布第二个产品；
- Runtime HTML P0、服务端 Publication、授权、支付、退款和责任 Gate 已关闭。

### 下调到 35–45 分并停止当前方向

- 历史需求主要由团队解释或教育，创作者无法提供重复咨询 / 人工付费证据；
- Combo 与通用模型在盲测中无显著差异，买家只为创作者人格尝鲜；
- 只有高比例人工补交付才能控制退款，且完整贡献毛利无改善路径；
- 创作者不愿再次发布，或自然观察窗内没有重复任务信号；
- 支付、授权、数据权利或责任路径无法合法、稳定地完成。

## 七、当前投资决定

**项目质量判断：** Combo 是一个值得继续验证的高方差 S0 项目。方向没有被否决，且团队与工程让它优于纯故事项目；但当前证据不足以证明产品成立，更不足以为 Marketplace 或平台期权付费。

**当前动作：等待里程碑。** 不建议继续用更多宏大市场研究、终局图或 Agent 数量提高融资说服力。下一轮尽调资源只投向一个 SKU 的历史需求、盲测、现金订单、退款 / 复购和逐单贡献毛利。

**交易判断：暂不提供。** 由于未给出估值、融资额、持股比例、清算优先权、资金用途、runway 和基金 mandate，本报告不评价价格是否便宜或能否达到基金回报。
