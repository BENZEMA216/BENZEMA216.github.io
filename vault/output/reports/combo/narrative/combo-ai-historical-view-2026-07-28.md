# Combo 的 AI 历史观

> 查询：结合《梁文锋投资者交流会》文字稿与 Combo 已有故事，回答“我们的 AI 历史观是什么”。
>
> 证据边界：用户提供的 PDF 是自动转写与 AI 整理稿，稿内也注明说话人、专有名词和数字可能有误。本文只提炼其中的路线判断，不把数字和时间表当作已核验事实。

## 一句话

> **AI 的历史，是通用认知与普通执行不断被工业化、低价化，人的部分能力不断被 Agent 化；Combo 押注的不是“人永远比模型强”，而是当“会做”越来越便宜，社会仍需要一个网络，把不同人的方法放进不同用户的 Context，持续交付其愿意付费的结果，让每次消费改进供给，并让能力贡献者从复用中获得收益。**

更短的版本是：

> **模型把智能变成基础设施，Agent 把能力变成可复制供给，Combo 把这些供给变成具体用户愿意购买的结果。**

## 一、梁文锋讲的是“智能生产史”

这份交流稿中有四个连贯判断：

1. AI 的技术进展是一条累积阶梯：`语言模型 → CoT → Agent → 持续学习 → 自我迭代 → 具身`。产品会变化，但前一层能力会成为后一层基础。
2. 当前模型在上下文和指令完整时已经很强，真正限制长期替代的是持续学习与长期 Context。
3. 同一技术范式中的模型能力可能逐渐收敛，竞争越来越落到成本、到达时间和体验；通用智能会更便宜、更开放。
4. 前沿模型变化太快，Chatbot、广告、电商、本地生活等具体产品线的半衰期很短；模型公司不必独占所有应用价值。

因此，梁文锋真正讲的是：

> **智能如何被生产、扩散和继续升级。**

它解释了为什么模型层会走向少数供给者、低成本和基础设施化，但没有直接回答智能进入社会之后，谁组织需求、谁形成服务、谁完成交易、谁获得收益。

## 二、Combo 补的是“智能进入社会后的经济史”

Combo 接受梁文锋关于能力和成本的方向判断，但把观察点从模型公司移到用户与专业服务：

```text
互联网规模化信息与分发
→ SaaS 规模化工具和工作流
→ 基础模型规模化通用认知
→ Agent 规模化任务执行
→ 人的部分方法被封装成可重复调用的供给
→ 专业服务从出售工时，部分转向出售有边界的结果
→ 真实消费留下 Context、结果和 Verdict
→ 只有当这些记录改善下一次供给与路由时，网络才成立
```

这条线索的关键不是“Agent 会越来越多”，而是劳动的商品单位发生变化：

| 历史阶段 | 被规模化的对象 | 用户真正得到什么 | Combo 的判断 |
|---|---|---|---|
| 互联网 | 信息与注意力 | 内容、连接和交易入口 | 解决信息分发，不直接完成专业工作 |
| SaaS | 工具与标准工作流 | 更高效地自己做 | 软件化工具，没有软件化工作本身 |
| 基础模型 | 通用认知能力 | 低成本答案和生成 | Combo 不做模型，模型是可替换生产资料 |
| Agent | 多步执行与工具调用 | 一部分任务被自动完成 | 通用编排会商品化，Agent 本身不是商品价值 |
| Agentic 专业服务 | 人的方法在具体 Context 中被重复应用 | 可使用、可验收的结果 | 这是 Combo 当前下注的最小商业单元 |
| 结果与路由网络 | 跨供给的交易、反馈和适配 | 遇到问题时持续得到合适结果 | 只有跨供给复购、站内需求和路由增益出现后才成立 |

这也解释了内容平台为什么仍可能出现。传统内容主要让用户“看见一个人怎么想、怎么做”；AI-native 内容可以进一步成为能力入口：

```text
看见别人完成了什么
→ 识别“这件事也适用于我”
→ 把同一种方法应用到自己的 Context
→ 获得自己的结果
```

因此，内容是需求形成和供给发现层，交易是价值兑现层，Agent 是生产方式。三者可以长在同一个产品里，但不能被混成同一个概念。

## 三、我们对“人的独特性”的准确立场

我们不相信一个浪漫版本：

> 人拥有某种模型永远无法复制的神秘能力，因此人的 Agent 永远值钱。

梁文锋甚至直接判断 AI 并不缺品味和直觉，缺的是持续学习。即使不同意这句话的强度，它也迫使 Combo 把“人的独特性”从哲学断言改成品类级事实。

Combo 的立场应拆成三层：

### 1. 商业事实：人的方法只在产生结果增益时有价值

一个真人衍生 Agent 必须在同条件下比通用模型带来更好的结果、更低的总成本、更高的成功率或更高的复购。没有这些增益，这个 SKU 就会被通用模型消灭，正版授权本身也不足以创造付费。

### 2. 供给机制：差异不等于人必须出现在前台

人的案例、方法、标准、动态经验和纠正可以在后台影响交付。消费者完全不知道背后是谁，只要结果更好，也可以是成功。

人的重要性体现在供给如何形成、由谁授权、如何持续更新，以及收益如何回到贡献者；这些是产生好结果和可持续供给的机制，不是用户购买的商品。

### 3. 规范性选择：人的贡献不应被匿名模型无偿抹去

即使市场最终只看结果，Combo 仍可以选择建立来源、授权、撤回和收益分配机制。它表达的是我们想建设怎样的经济制度，但不能被当作市场已经愿意付费的证据。

## 四、用户价值始终只有一个：更好地把事情做成

用户不为“人机协同”“判断”“责任”“承诺”或“动态组织”本身付费。他购买的是：

> **一份范围、价格、时限、交付物和失败补救都清楚，并且真正适合自己的结果。**

Context、真人升级、授权、评价、退款和责任边界都重要，但它们属于生产与保障机制。只有当它们让结果更好、更省心、更稳定或更便宜时，才形成商业价值。

因此，Combo 的最小历史单位不是一条内容、一个 Agent 或一次对话，而是一次真实 `Run`：

```text
用户目标与 Context
→ 调用某项真人衍生能力
→ 模型、工具与必要真人共同执行
→ 交付具体结果
→ 用户接受、修改、拒绝或退款
→ 反馈改善这个用户的适配或后续供给
```

## 五、我们确定什么，不确定什么

### 高置信度环境判断

- 模型会继续增强，普通生成、检索、拆解和编排会持续降价；
- Prompt、Agent Builder、模型选择和通用 Workflow 很难成为长期壁垒；
- Agent 会把更多认知能力变成行动能力，但用户仍按结果、成本、速度和省心程度评价；
- 模型越便宜，Combo 的履约成本越低，普通结果的售价也越容易归零；
- 基础模型和默认入口可能集中，应用供给是否分散仍取决于行业结构。

### Combo 成立所依赖的 Bet

- 至少一部分有边界任务中，真人方法相对最强通用模型仍有可感知、可付费的结果增益；
- 这种增益能被 Agent 重复交付，而不是每单都由专家重新完成；
- 真实的 `Context + 行动 + 结果 + Verdict` 能改善下一单，而不只是增加聊天日志；
- 用户会从一次 KOL 交易，逐渐产生对 Combo 的复购、跨供给购买或路由信任；
- 能力贡献者愿意授权、持续纠正，并能从 Agent 使用中获得净增量收益；
- 模型与超级入口不会把供给、交易、履约和用户关系全部封闭在自身生态中。

### 我们明确不相信

- 不相信模型越强，Combo 就必然越强；
- 不相信每个人的独特性都具有商业价值；
- 不相信更多 Agent、Context 或评价会自动形成数据飞轮；
- 不相信横向 Marketplace 会从开放上架自然冷启动；
- 不相信五年后专家一定经营数字工作室；
- 不把“行动互联网”“承诺互联网”或“协同互联网”当作已经存在的产品类别。

## 六、这套历史观必须可以被证伪

| Bet | 最小验证 | 失败后的判断 |
|---|---|---|
| 真人衍生供给有增益 | 与同代最强通用模型做盲测、付费和复购对照 | 无稳定增益的 SKU 删除 |
| AI 让服务软件化 | 观察每单真人分钟、首次成功率、退款和全成本贡献毛利 | 人工随订单线性增长，则只是 Agency |
| Context 产生价值 | 关闭 Context 做对照，比较 intake、结果、成本与退款 | 无显著变化，不讲 Context moat |
| 评价改善供给 | 比较版本迭代前后的成功率、返工和复购 | 只积累评价、不改变指标，则没有数据飞轮 |
| 信任转移到 Combo | 第二单、跨 KOL 购买、平台推荐接受和售后挽回复购 | 用户始终只跟随 KOL，则停在创作者工具 |
| 网络能够成立 | 平台新增 GMV、跨供给流动与路由增益同时出现 | 可以成为垂直结果公司或服务商 OS，不强讲横向平台 |

## 七、给 VC 的三句话

> **SaaS 把工具软件化，AI 正在把工具背后的部分工作软件化。**
>
> **Combo 从有信任和分发的垂类 KOL 开始，把一项反复提供的专业服务做成可收费、可规模化交付的 AI 结果产品。**
>
> **如果用户会持续复购、跨供给购买，而真实结果与评价能改善下一次交付，Combo 才会从创作者变现工具升级为 AI-native 专业服务的交易与路由网络。**

这比“我们相信人不会被 AI 替代”更适合投资论证。它同时交代了结构性变化、当前 wedge、条件式上限和反证路径。

## 最终判断

Combo 的 AI 历史观可以叫：

> **认知劳动工业化，专业能力 Agent 化，结果交易网络化。**

但最后一段必须保留：

> **这不是必然历史。模型可能直接消灭大量结果 SKU，大厂可能封闭交易入口，人的差异也可能无法产生付费优势。Combo 的任务不是证明一套哲学，而是从一项真实服务开始，找到哪些能力在 AI 变强后仍值得被授权、调用和付费，并用结果数据决定是否有资格走向网络。**
