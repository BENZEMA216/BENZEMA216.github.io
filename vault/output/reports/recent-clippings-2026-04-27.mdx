## 主题判断

### 1. Harness 正在从工程技巧变成平台原语

LangChain 的 Harness 文章、Harrison Chase 访谈、OpenAI Ryan Lopopolo 的极端 Codex 实验、Anthropic Managed Agents、OpenAI Agents SDK、Notion Custom Agents 都指向同一件事：**模型能力本身不再是产品落地的充分条件，真正的竞争在 model 周围的 harness、sandbox、filesystem、tool routing、eval、spec 和 observability。**

这一批材料里有三条收敛线：

- **Agent-legible software**：OpenAI Frontier / Symphony 把代码库、构建系统、PR 流程、文档和 quality score 都改造成 agent 可操作对象。
- **Meta-harness**：Anthropic Managed Agents 把 Brain / Hands / Session 解耦，押注未来 harness 会继续变化，所以稳定的是接口而不是实现。
- **Model-native harness**：OpenAI Agents SDK 把 MCP、Skills、AGENTS.md、shell、apply_patch、sandbox manifest 组合成 SDK 层，和 Anthropic Managed Agents 形成同题竞争。

### 2. Agent 平台从“聊天入口”转向“工作/生活连接器 + 能力市场”

Claude connectors、Notion Custom Agents、Pika AI Self、OpenAI Codex App、Softr AI app builder 都不是单纯 chat UI，而是在做两件事：

- 把用户已有工具、账号、数据源接入 agent。
- 把能力包装成可授权、可运行、可计费的产品单元。

Notion 的复盘最有价值：它把复杂 block / database API 改造成模型熟悉的 Markdown / SQL，说明 **agent 产品的关键不是暴露真实系统，而是暴露模型最容易稳定使用的系统表征**。

### 3. Agent Economy 进入真实世界压力测试

Project Vend Phase 1/2、Agent 支付协议文章、Pika 的 AI Self monetization、Agent Labs 文章共同把 “agent 能不能赚钱/付钱/被分发” 拉到同一层。

核心结论不是“agent 已经可以独立经营”，而是：**capable 与 robust 之间还有很宽的鸿沟**。Project Vend Phase 2 通过 CRM、库存成本可见、浏览器搜索、payment link、reminder、CEO sub-agent、merch sub-agent 提升了经营表现，但仍暴露 helpfulness bias、客户对抗、法律常识、授权边界和身份混淆问题。

对 BENZEMA 方向的启发：agent economy 的机会不在“又一个协议”，而在 **agent 的管理层、授权层、支付边界、争议处理和声誉系统**。

### 4. 协议层已经分化：通信、工具、支付、安全是四条线

这批剪藏把协议空间拆得更清楚：

- **MCP**：model/tool/context 协议，适合工具调用和资源访问。
- **ACP/A2A**：agent-to-agent peer communication，避免把 agent 降格成 host 调用的工具。
- **MPP / x402 / ACP / AP2**：agent payment / commerce 协议，围绕 HTTP 402、stablecoin、shared payment tokens、电商授权展开。
- **MCP security**：Astrix 对 5,200+ MCP server 的研究显示，credential 管理是当前最大风险面，尤其是静态 API key / PAT 与 env var 注入模式。

协议不是一个层，而是一组互相叠加的能力边界：通信、动作、身份、凭证、支付、审计、争议。

### 5. Benchmark 正从静态分数转向“真实任务时间、运行环境、可观测性”

METR long-task horizon、Browser Arena、LangChain State of AI Agents、Google Vantage 是同一趋势的不同侧面：

- METR 用人类任务时长衡量 agent 能独立完成的任务 horizon，提出约 7 个月翻倍趋势。
- Browser Arena 把 cloud browser provider 的 session create / CDP connect / navigation / release 延迟、可靠性和成本变成 leaderboard。
- LangChain State of AI Agents 显示 production 已成主流问题，质量、延迟、security、observability、eval 才是落地瓶颈。
- Google Vantage 用 AI avatars + Executive LLM + AI Evaluator，把人类 durable skills 的评估转成可控模拟任务。

这说明 agent eval 的下一个重点不是“答题正确率”，而是 **长程任务、环境成本、失败可解释性和真实交互压力**。
