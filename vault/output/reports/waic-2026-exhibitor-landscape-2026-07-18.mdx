# WAIC 2026 上海参展企业全量资料与产业图谱

> 生成时间：2026-07-18  
> 查询：全面获取今年在上海举办的 WAIC 参展企业资料  
> 数据范围：WAIC 官网公开企业目录、公开展品目录、WAIC 官方展商图、上海区政府/园区发布与上海市政府发布会口径；快照数据以 2026-07-18 抓取结果为准，重点产品外部链接于 2026-07-19 核验。

## 摘要

这次交付完成了 **WAIC 2026 官方公开数据层的全量抓取、结构化、去重与可筛选工作簿**：

- 官方企业目录 API 返回 **1,020 条记录、1,020 个唯一企业代码**；
- 其中 **918 条明确带“展商”身份**，**92 条仅为论坛主办方**，另有 **10 条身份未标注**；918 条中再合并 ApartX 与 Oxtak 两对明显重复档案后，为 **916 家目录去重展商**；
- 目录内 **1,011 条有中文名称**、**993 条有中英文简介**、**904 条有 Logo**、**870 条有展位**；
- 一共展开出 **901 条展位关系**，其中 **28 条企业记录拥有多个展位**；
- 官方公开展品 API 返回 **1,394 行**，去掉 5 个完全重复的 `productCode` 后为 **1,389 件唯一展品**，关联 **461 个企业代码**；
- 官方企业目录并不是唯一公开面：展品 API 另确认 2 家目录外企业，WAIC 官方展商长图补 24 个单位，区政府/园区发布再补 41 个共享或轮换参展单位/品牌；因此形成 **916 → 942 → 983** 的三层可复核口径；
- 已交付 Excel 工作簿，含“概览、企业名录、展位明细、展品明细、重点产品链接、补充参展单位、分类统计、数据字典”8 个 sheet，同时保留 CSV、JSON 和原始 API 快照供复核；产品链接核验详见 [waic-2026-priority-product-links-2026-07-19](/output/reports/waic-2026-priority-product-links-2026-07-19/)。

最重要的口径区别是：上海市政府发布会称本届有 **1,100 余家企业、3,000 余项展品、300 余项全球首发**，而官网当前公开 API 只返回 1,020 条企业目录记录和 1,394 行展品。跨 WAIC 官方资产与政府/园区来源补齐后，目前能逐一列名、追溯来源的是 **983 个参展单位或品牌**；这仍不是对全部线下参展主体和全部现场展品的虚假满覆盖。[上海市政府发布会](https://www.shanghai.gov.cn/nw12344/20260707/deee99228f02433e9b0fb8f9447e8b34.html)

## 二、六层数量口径

| 层级 | 数量 | 应如何理解 |
|---|---:|---|
| 官方大会总体口径 | 1,100+ 家企业 | 上海市政府发布会披露的大会规模；不是可枚举精确名单 |
| 官网公开企业目录 | 1,020 条 | 当前官网目录 API 的完整快照，混合展商与论坛主办方 |
| 严格展商身份 | 918 条 | `roleCode` 明确包含展商身份；适合做参展企业统计 |
| 官网目录去重展商 | 916 家 | 合并 ApartX 与 Oxtak 两对明显重复档案后的实体计数 |
| WAIC 官方资产可确认 | 942 个单位 | 916 家 + 展品 API 补 2 家 + WAIC 官方展商长图补 24 个单位；其中 KIC 中国是机构 |
| 多源可确认参展单位/品牌 | 983 个 | 再加区政府和园区发布中明确点名的 41 个共享或轮换单位/品牌 |
| 论坛主办方但非展商 | 92 条 | 在官网目录中出现，但不能自动算作展商 |
| 身份未标注 | 10 条 | 9 条没有中文名；另 1 条为极客众工科技有限公司 |

这里不应该用一个数字取代另外几个：1,100+ 是大会规模口径，1,020 是公开目录记录口径，918 是严格身份记录，916 是目录实体去重结果，983 是当前多源可确认的单位/品牌口径。对外写“全量”时，应写成“截至 2026-07-18 的公开来源可复核全集”，不能声称拿到了大会内部最终名录。

新增的 67 条线索中，2 条来自 WAIC 展品 API，24 条来自 WAIC 官方账号发布的展商长图，7 条来自[长宁区政府发布](https://www.shanghai.gov.cn/nw15343/20260716/bdbdfd4c003b4e8cbfa986142fbc9318.html)，12 条来自杨浦区官方发布，22 条来自张江园区发布。共享展位、轮换项目和品牌短名全部单列，不与法人企业静默合并。

## 六、展品数据的价值与边界

公开展品目录可用于回答“哪家公司带了什么、在哪个展位、属于哪个行业”：

- 原始 API 1,394 行，按 `productCode` 去重为 1,389 件；
- 1,389 件都带中文名、中文描述和展位号；
- 展品关联 461 个企业代码，其中 459 个能匹配企业目录；
- 未匹配的两家为郑州城发安居有限公司（展品“智能驾驶舱”）和广州万协通信息技术股份有限公司（展品“可重构 TPU 芯片”）；
- 只有 22 条有非空全球首发状态，22 条有非空国内首发状态；`isNewProduct` 全部为 false，因此不能据此反推大会的 300+ 全球首发总体口径。

产品 API 明显只是公开子集：1,389 件远低于官方“3,000+ 展品”。工作簿保留原字段，但没有把空值或 false 擅自解释成“不是新品”。

## 七、数据质量与风险

1. **动态快照**：大会仍在进行，目录可能继续增删；建议闭幕后再抓一次最终快照并做差异比较。
2. **历史年份参数不可信**：接口即使传入 2025 等年份，仍返回 2026 数据；不能用同一接口回溯历届名单。
3. **目录与总体规模不一致**：跨来源补齐后也只逐一确认到 983 个单位或品牌，与政府发布会的 1,100+ 企业口径仍有缺口，主要可能来自未完整公开的联合展团、轮换项目和品牌—法人别名。
4. **9 条空名称记录**：均保留企业代码与原始字段，不伪造名称。
5. **多展位与多档案重复风险**：28 条企业记录有多个展位；ApartX 和 Oxtak 各出现两个明显重复档案。统计公司实体时既要按 `enterpriseCode` 保留官方记录，也要再做实体归一。
6. **展品覆盖不完整**：公开 1,389 件唯一展品不能代表现场 3,000+ 件全部展品。
7. **外部企业画像尚未混入**：成立、总部、融资、上市与联系人需要逐字段来源追溯，不能用搜索摘要或名单售卖站批量猜测。

## 八、建议的使用方式

- **找潜在客户或合作伙伴**：在“企业名录”按行业一级分类、服务领域、合作伙伴等级和是否有展位组合筛选，再读官方企业简介。
- **找新品与技术方向**：在“展品明细”按展品行业、企业、展位和首发字段筛选；不要仅依赖 `isNewProduct`。
- **安排现场路线**：用“展位明细”按展馆、展厅或区域、展位号排序；多展位企业可选择最近的一处。
- **检查共享与轮换项目**：用“补充参展单位”查看海峡展团、长阳秀带、模力社区等目录外单位；短名和品牌名应先完成法人归一，再导入 CRM。
- **做竞品或投资研究**：先从 FT 初创、OPC、创投生态和具身智能/核心技术标签选样本，再进入第二阶段核验官网、成立时间、融资和团队。
- **导入 CRM/数据库**：以 `(2026, enterpriseCode)` 作为本届目录主键；品牌、集团、法人和子公司仍需独立实体解析。
